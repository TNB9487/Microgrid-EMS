# Smart Microgrid Energy Management System (EMS)

A Python-based simulation and technical report exploring automated energy control for localized microgrids.

## Overview
This project simulates a 24-hour smart microgrid that coordinates solar power, diesel generation, and battery storage to meet fluctuating electricity demands.
The system uses automated decision-making rules to manage battery charging and perform priority-based load shedding during energy deficits, ensuring critical infrastructure stays powered.

## Key Features
Smart Power Dispatch: Balances renewable solar generation with conventional diesel power.
Battery Storage Management: Models real-world energy charging and discharging losses.
Priority Load Shedding: Protects essential facilities (e.g., Hospital) during power shortages.
